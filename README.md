# Unraid Setup

This repo is meant as a general knowledge base for Unraid, including:

- installing Unraid with some reasonable default configurations
- explaining various concepts used in Linux that apply to Unraid
- exploring some optional advanced implementations around networking and software options

This should help you figure out where to start looking if you are completely lost on what to do.

Anything around general knowledge is in the [docs](/docs) folder, and anything else will 
generally have README's explaining what they are, (or, there will be relevant links in the docs
to said things when such arises).

I recommend starting on the [install docs page](/docs/install_unraid.md).
